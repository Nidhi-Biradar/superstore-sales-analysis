Superstore Sales Analysis Dashboard

About the Project
This project analyses a Superstore sales dataset containing 9,800 records to identify sales trends and business insights.

Tools Used
- Google Sheets

Analysis Performed
- Sales by Year
- Sales by Category
- Sales by Region
- Sales by Segment
- Sales by State
- Sales by Shipping Mode
- Top 10 Products by Sales

Key Insights
- 2018 recorded the highest yearly sales.
- Technology was the top-performing category.
- West was the highest-performing region.
- California recorded the highest sales.
- Standard Class accounted for approximately 59.3% of total sales.
